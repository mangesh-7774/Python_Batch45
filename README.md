# 🐍 Python Batch 45

Welcome to the **Python Batch 45** repository.

This repository is created to help contributors practice **Python programming** while learning **real-world Git and GitHub collaboration**.

Every contributor will complete assigned programming tasks, submit their work through **Pull Requests**, and receive code reviews before their code is merged into the `main` branch.

# 📌 Repository Rules

- Do not push directly to the `main` branch.
- Work only on the issue assigned to you.
- Create a new feature branch for every task.
- Add your program to the correct folder.
- Use meaningful file names.
- Follow Python coding standards.
- Submit a Pull Request after completing your task.
- Wait for review and approval before merging.

---

# 📌 Branch Naming Convention

Use the following format when creating branches:

```
feature/program-name
```

Examples:

```
feature/palindrome
feature/armstrong
feature/reverse-string
feature/star-pattern
```

---

# 📌 Commit Message Format

Write clear commit messages.

✅ Good Examples

```
Add palindrome program
Add Armstrong number program
Fix prime number logic
Refactor reverse string program
```

❌ Bad Examples

```
Done
Update
Changes
Final
abc
```

# 📌 Pull Request Process

1. Complete the assigned issue.
2. Test your program.
3. Commit your changes.
4. Push your feature branch.
5. Create a Pull Request.
6. Wait for review.
7. Make requested changes if required.
8. Once approved, the Pull Request will be merged into `main`.

---

# 📌 Code Review Checklist

Before submitting your Pull Request, ensure:

- Program runs without errors.
- Correct output is produced.
- Meaningful variable names are used.
- Functions are used where appropriate.
- Code is properly formatted.
- Unnecessary code is removed.
- File is placed in the correct folder.
